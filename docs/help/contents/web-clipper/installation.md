# Installation

## Chromium-based browsers

[Go to chrome webstore](https://chrome.google.com/webstore/detail/opennotes-web-clipper/kljhpemdlcnjohmfmkogahelkcidieaj) to get the latest version of [web clipper for OpenNotes](https://opennotes.openlay.com/opennotes-web-clipper).

## Firefox-based browsers

1. Download the .xpi file from [here](https://opennotes.openlay.com/opennotes-web-clipper)
2. A pop-up will appear, select "Continue to Installation".
3. Select "Add".
